# Дневник мыслей — твоё PWA

Личный дневник для iPhone: мысли, задачи, цели, планы и записи по дням.
Работает офлайн, ставится на главный экран как обычное приложение.

## Что внутри

- `index.html` — всё приложение (вёрстка, стили, логика)
- `manifest.json` — описание PWA для iOS
- `sw.js` — service worker для офлайн-режима
- `icon-192.png`, `icon-512.png` — иконки приложения

## Как опубликовать на GitHub и поставить на iPhone

### 1. Создай репозиторий на GitHub

1. Зайди на [github.com](https://github.com) → **New repository**
1. Имя: например, `diary` (любое)
1. Поставь **Public** (иначе GitHub Pages не заработает на бесплатном тарифе)
1. Создай репозиторий

### 2. Залей файлы

Самый простой способ — через сайт:

1. На странице репозитория нажми **Add file → Upload files**
1. Перетащи все 5 файлов (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`)
1. Нажми **Commit changes**

### 3. Включи GitHub Pages

1. В репозитории зайди в **Settings → Pages**
1. В разделе **Source** выбери ветку `main` и папку `/ (root)`
1. Нажми **Save**
1. Подожди 1–2 минуты — GitHub покажет адрес вида
   `https://твой-логин.github.io/diary/`

### 4. Поставь на iPhone

1. Открой полученную ссылку в **Safari** (важно — именно Safari, не Chrome)
1. Нажми кнопку **Поделиться** (квадрат со стрелкой вверх)
1. Прокрути и выбери **На экран «Домой»**
1. Нажми **Добавить**

Готово — на главном экране появится значок «Дневник». Открывай его как обычное приложение. Работает офлайн.

## Память (данные)

- Все записи хранятся локально на твоём iPhone (в Safari `localStorage`).
- В меню (≡ в правом верхнем углу) есть:
  - **Скачать память** — выгружает все данные в `.json` файл (можно сохранить в iCloud Drive, отправить себе на почту, в Telegram и т.д.)
  - **Загрузить память** — восстановить из такого файла на другом устройстве или после переустановки

### Важно про сохранность данных

Так как это PWA, данные хранятся в Safari. Они **могут потеряться**, если:

- ты очистишь данные сайтов в настройках Safari
- iPhone не открывал приложение очень долго (iOS чистит давно неиспользуемое)

**Поэтому раз в неделю-две делай экспорт памяти и сохраняй файл в iCloud Drive или почту.** Это твоя страховка.

## Возможности

- 5 разделов по умолчанию: Мысли, Задачи, Цели, Планы, Дневник (записи по дням)
- Можно добавлять, переименовывать, удалять разделы (меню → Управлять разделами)
- 3 типа разделов:
  - **Заметки** — обычные записи
  - **Задачи** — можно отмечать как «Готово»
  - **По дням** — автоматически группирует записи по датам
- Редактирование и удаление каждой записи
- Работает офлайн
- Экспорт/импорт всех данных в файл

-----

## Если что-то не работает

- **Service worker не регистрируется** — это нормально на `file://`, нужен GitHub Pages (https://)
- **Иконка не та после переустановки** — удали приложение с главного экрана, очисти кэш Safari для сайта, добавь заново
- **Данные пропали** — восстанови из последнего экспортированного `.json` через меню → Загрузить память
